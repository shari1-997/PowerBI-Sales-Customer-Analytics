# Security Policy

## Scope
This is a portfolio demonstration project, not a production application or hosted service.

## Reporting a Concern
If you identify a security or privacy concern in the repository, please avoid publishing sensitive details in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile.

## Data Handling
- Do not upload passwords, access tokens, private customer records, or confidential business data.
- Treat dataset names and records as sample portfolio data.
- Review files before sharing them publicly to ensure they contain no private information.

## Response Expectations
This project is maintained as a portfolio example, so response times are not guaranteed.
