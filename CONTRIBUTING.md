# Contributing

Thank you for your interest in improving this portfolio project.

## Suggested Contributions
- Report documentation errors or unclear explanations.
- Suggest improvements to report accessibility or usability.
- Identify reproducible issues in calculations or visual interactions.

## Before Submitting
1. Describe the issue or proposed improvement clearly.
2. Include the affected report page or file.
3. If applicable, provide steps to reproduce the issue.
4. For visual changes, include a screenshot.
5. Do not submit private, confidential, or personal data.

This is primarily a learning and portfolio project; contributions may not be reviewed on a fixed schedule.
